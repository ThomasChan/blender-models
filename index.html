02 / 怎么用

三步，从看到用

01

在页面里看

详情页是一个真的 WebGL 转台，不是视频。拖动可以停在任意角度，鼠标松手后回到匀速自转；地址栏的 ?m= 参数就是当前模型，可以直接分享。

02

在本地跑

serve.py 不带任何依赖，只做静态文件加 /api/models。往目录里丢一个 .glb，刷新就能看到，不需要先构建清单。

terminal
git clone https://github.com/ThomasChan/blender-models
cd blender-models
python3 serve.py            # http://127.0.0.1:8777/
03

加一个模型

一个文件夹一个产品：product.glb + 同名 product.json（写 title）。线上读的是提交进仓库的 models.json，所以提交前要重建一次。

terminal
mkdir myproduct && cp myproduct.glb myproduct/
printf '{ "title": "My Product" }' > myproduct/myproduct.json
python3 build_manifest.py   # 本地 serve.py 会实时扫描，线上需要这一步

缩略图可选：放一张 800px 的 thumb.webp；没有就用 preview-hero.png。gallery 不会去加载 1.3 MB 的原始渲染图。

01

在前端项目里使用模型

给 agent 的指令：

prompt
在这个项目里用 https://chenjunhao.cn/blender-models/ 的模型。
- 清单是 models.json，每项有 url / thumb / tris / bytes / fix；GLB 单位是米、Y 轴向上。
- Pages 返回 Access-Control-Allow-Origin: *，可以直接跨域 fetch。
- 用 three.js 的 GLTFLoader；Level 1 优化后的 GLB 大多带 EXT_meshopt_compression 和
  KHR_mesh_quantization，必须 loader.setMeshoptDecoder(MeshoptDecoder)，否则几何体加载不出来。
  统一挂上 decoder 对未压缩的 GLB 也无害。
- 金属材质没有环境贴图会发黑：给 scene.environment 一张 PMREM 过的环境。
- renderer 用 THREE.NeutralToneMapping，toneMappingExposure = 1.25，和本页预览一致。
- fix 非空的模型（目前只有 macmini）必须按 viewer.js 里 show() 的规则应用，否则会刻面、AO 错位。
- 不要改 GLB；尺寸和每个模型的取舍写在 README 里。
three.js
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { MeshoptDecoder } from 'three/addons/libs/meshopt_decoder.module.js';
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.toneMapping = THREE.NeutralToneMapping;
renderer.toneMappingExposure = 1.25;

const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture;

const loader = new GLTFLoader().setMeshoptDecoder(MeshoptDecoder);
loader.load('https://chenjunhao.cn/blender-models/imac27/imac27.glb', gltf => {
  scene.add(gltf.scene);          // 模型自身就在真实尺寸和原点附近
});
  • 把 meshopt decoder 当成默认配置。Level 1 优化后的模型大多用它压缩；未压缩的 GLB 挂了也不会有害。具体看 extensionsUsed 里有没有 EXT_meshopt_compression。
  • 环境贴图不是可选项。这批模型的壳体和支架是金属，像素值全部来自反射；没有 scene.environment 时它们会渲染成深灰。
  • 别在 three.js 里重新归一化尺寸。GLB 已经是米制真实尺寸；本页的等比缩放只是为了转台好看，接进你的场景时按需要自己摆。
02

安装并使用 blender-highpoly 技能

这是一套给 agent 的建模流程：先查厂商有没有公开 USDZ，再决定转换还是手建；写完一个构建脚本，最后必须过导出闸门。

terminal — 从仓库安装
git clone https://github.com/ThomasChan/blender-models /tmp/blender-models
mkdir -p ~/.agents/skills
cp -R /tmp/blender-models/skills/blender-highpoly ~/.agents/skills/

# Claude Code 读 ~/.claude/skills，软链过去即可
mkdir -p ~/.claude/skills
ln -sfn ~/.agents/skills/blender-highpoly ~/.claude/skills/blender-highpoly
prompt
用 blender-highpoly 这个 skill 给 <产品> 建一个高精度模型：
- 真实毫米尺寸，常数全部从规格页抄下来再换算，不要用混合单位。
- 只写一个构建脚本，顺序是几何 → 材质 → 灯 → 渲染 → 导出 → 保存 .blend。
- 导出后用 ~/.agents/skills/blender-highpoly/scripts/check-model.py 过闸门，
  --expect 填实测尺寸，--render 出至少两张预览；把 FAIL 当错，不要当警告。
- 动手前先查这个产品有没有官方公开的 USDZ / glTF，有就转换，没有才手建。
terminal — 导出闸门
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup \
  --python-exit-code 1 \
  --python ~/.agents/skills/blender-highpoly/scripts/check-model.py -- \
  out/model.glb --expect 127,127,50 --render out/hero.png
  • 技能里有什么：SKILL.md 是工作流和踩过的坑；references/bpy.md 是 Blender API 的单位表；references/craft.md 是尺寸与材质做法；scripts/check-model.py 会重新导入导出的 GLB，量尺寸、数 n-gon / 非流形、看曝光。
  • 闸门量的是导出的文件，不是内存里的场景。所以它抓得到导出选项、轴向、缩放这类“脚本里全对、文件里全错”的问题。
  • 它不判断像不像。识别度、构图、开孔是不是真的能看穿，仍然要靠人看渲染图——技能里把这条写成了硬规则。
